# تطبيق فيديو الأطفال (KidsVideo)

متصفح بسيط يشغّل YouTube وأي موقع فيديو بملء الشاشة، مع "وضع أطفال" يخفي الأزرار ويثبّت التطبيق.
يعمل على هاتفك، وتظهر الشاشة على الشاشة الخلفية عبر الوصلة التي تستخدمها حالياً (HDMI / Miracast / غيرها).

## طريقة بناء ملف APK

1. ثبّت **Android Studio** (مجاني) من developer.android.com/studio
2. افتح المجلد (File ► Open) واختر مجلد المشروع هذا، وانتظر انتهاء مزامنة Gradle.
3. من القائمة: **Build ► Build Bundle(s) / APK(s) ► Build APK(s)**
4. يظهر إشعار "locate"، وملف APK يكون في:
   `app/build/outputs/apk/debug/app-debug.apk`
5. انقل الملف إلى هاتفك وثبّته (فعّل "التثبيت من مصادر غير معروفة" إن طُلب).

## طريقة الاستخدام

- اكتب كلمة بحث أو رابطاً في الشريط العلوي، أو اضغط **YouTube**.
- اضغط **🔒 أطفال** لإخفاء الشريط وتثبيت الشاشة.
  - عند أول مرة يعرض أندرويد رسالة "تثبيت الشاشة"، اضغط موافق.
  - لإلغاء القفل: اضغط **مطولاً** على الزاوية العلوية اليسرى من الشاشة (مربع شفاف).
  - إن لم يعمل، اضغط مطولاً على زري الرجوع والتطبيقات الأخيرة معاً.
- زر الرجوع يعمل داخل المتصفح، ويُتجاهَل في وضع الأطفال.

## ملاحظات

- الشاشة تبقى مضاءة أثناء فتح التطبيق.
- إن لم تظهر رسالة تثبيت الشاشة: الإعدادات ► الأمان ► تثبيت الشاشة (Screen pinning) ► تفعيل.
- لمنع الأطفال من فتح محتوى غير مناسب، يفضّل تسجيل الدخول بحساب YouTube Kids/وضع مقيّد داخل YouTube.
